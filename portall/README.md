# Portall

Home Assistant, and any web page, on an ESP32-P4 panel over Wi-Fi. The page is
rendered on the machine that is already on all the time, sent to the panel as
JPEG rectangles, and the panel's touches are replayed back into it.

**The documentation is in [DOCS.md](DOCS.md)** -- options, the launcher, the
on-screen keyboard, sound, and what it costs. That is also the file Home
Assistant shows on the add-on's **Documentation** tab, which is why it is named
that and this one is short.

Coming from the old **ESP32-P4 Panel** add-on? Its slug was
`usb_display_panel` and this one is `portall`, so Home Assistant sees a new
add-on rather than an update: see **Moving from the old add-on** in DOCS.md for
the four steps.
